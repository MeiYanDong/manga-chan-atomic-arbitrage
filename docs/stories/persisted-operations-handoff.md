# Story：经营报表不再等待繁忙扫描进程

## Outcome

作为实盘经营者，我希望每五分钟更新的经营面板稳定显示最近一次可核验的市场摘要，同时明确它的观察时间，而不是
因为扫描进程短时繁忙就把运行中的市场栏整体变成未知。

## Acceptance criteria

- 看板完整发布后原子生成小型、字段白名单化的 operations snapshot；
- 报表在文件新鲜且看板 systemd 服务运行时使用该摘要，不发起 loopback HTTP 请求；
- 文件超过三分钟、权限可写、schema 不匹配或内容损坏时不得采用；
- 文件不可用时最多保留原有两次 loopback 请求，持续失败仍显示未知；
- 市场数据携带独立 `observedAt`，不得使用新报表时间冒充新市场观察；
- 摘要中不出现池明细、RPC 地址、provider 配置、钱包或签名材料；
- 写摘要失败不阻断 signer feed，不改变实盘执行器及任何经济门槛。

## Non-goals

- 不提高公共或付费 RPC 用量；
- 不扩大扫描图、资金、授权或链上执行范围；
- 不把历史市场数据当作当前可执行机会。
