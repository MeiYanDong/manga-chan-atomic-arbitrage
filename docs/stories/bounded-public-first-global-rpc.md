# 公共优先、成本有界的全局 RPC 故事卡

作为策略经营者，我希望全局套利在公共 RPC 限流时能够继续核验机会，同时清楚知道付费 RPC 的最大成本，
而不是在“经常漏掉机会”和“无限消耗套餐”之间二选一。

验收标准：

- 并发读取会组成 JSON-RPC batch；两笔同时读取只发出一个公共 HTTP 请求；
- 公共请求成功时，付费端点收到零次请求；
- 公共端点返回 429 或网络失败时，同一批只回退一次；
- 公共端点漏回一个 batch 项时，只为缺失的逻辑调用回退，不重复已成功项；
- `execution reverted` 等确定性合约结果不跨提供商重试；
- 付费回退按 batch 内逻辑调用数计费，先扣额度、再发请求；
- 当日用量和 20,000 次上限跨进程重启保存，并进入只读经营快照；
- v8 授权不匹配该上限时拒绝运行，额度耗尽时不签名、不广播、不消耗 Gas；
- 直连 Sequencer、同 raw 回退、nonce、receipt、利润门槛和单钱包签名通道均保持不变。
