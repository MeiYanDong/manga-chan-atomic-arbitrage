# Story: 高置信事件有限插队但不能饿死恢复扫描

## 用户结果

作为经营者，我希望刚发生的高置信市场变化尽快进入精确验证，同时仍能证明全局恢复扫描不会被持续事件
永久推迟。

## 验收标准

- Feed、托管 WSS 与已得出正候选的常驻搜索结果可以在 30 秒窗口内先于过期恢复任务执行；
- 普通公共补偿事件不能抢占过期恢复任务；
- 过期达到 30 秒后恢复任务无条件优先；
- 事件任务不改变周期任务原有 deadline；
- 签名通道仍为单通道，不允许 nonce 并发；
- 状态与审计记录策略版本、上限和实际发生的延后；
- 测试同时覆盖允许插队、硬截止、低优先级和周期不重置。
