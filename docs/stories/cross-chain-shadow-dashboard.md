# 故事卡：跨链独立场所影子机会面板

作为经营面板用户，我需要把 Robinhood Chain 与 BNB Chain 的独立流动性场所分开查看，并一眼知道数据是否完整、扣除 Gas 后是否还有机会，而不是阅读原生报价字段或把缺失数据误认为零。

## 验收标准

- Nginx 以只读静态接口 `/api/v1/opportunities/chains` 暴露独立扫描器的公开快照；
- 前端把 Uniswap/PancakeSwap 场所、资产范围、完成报价数、尝试数和净正机会数按链展示；
- `PARTIAL` 必须显示“数据不完整”，不能显示为“本轮无净正”；
- 页面不展示合约地址、RPC URL、fee tier、raw unit、钱包或签名字段；
- 文案明确影子净正不等于成交，只有执行准入、回执和余额增量才能记为收益；
- 接口或扫描器暂时不可用时保留其他经营数据，未知结果不会补成零；
- 接口只允许 GET/HEAD，带公共 CORS，且不依赖主市场板的事件循环。

## 不在本故事范围

- 不给 BNB 或 Robinhood 新场所授予签名、广播、资金或执行合约权限；
- 不把有限资产和金额档宣传为全链机会全集；
- 不因 Shadow 发现正值自动触发交易。
