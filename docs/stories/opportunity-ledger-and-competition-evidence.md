# Story：在一个页面看清机会、过滤与竞争证据

## Outcome

作为实盘经营者，我希望在不改变现有经营面板其他页面的前提下，通过一个新页面直接判断当前有无可执行机会、哪些机会被什么条件过滤，以及我们对错失机会和竞争者到底有多少证据。

## Acceptance criteria

- 主导航只新增 `机会`，原有四页职责不变；
- 页面将候选互斥分为“现在能做 / 接近门槛 / 已过滤 / 错过与未知”；
- 每条候选只展示资产、路线、测试本金、毛利、预估成本、预估净利润与中文结论；
- `NOW/NEAR` 的精确路线与本金延迟 5 分钟公开，已过滤原因立即可见；
- 当前报价、历史正价差、已确认成交和已证明被抢数量保持独立；
- 当缺少反事实或连续报价时，页面显示“待核验 / 部分待核验”，不显示 0；
- 原策略页仅在访问时请求最多 12 条机会摘要，全局 15 秒刷新不请求重型投影；
- Earn 竞争取证仅使用官方公共 RPC，不加载钱包、凭证、签名或广播能力；
- 回执必须精确匹配已审查池子、方向、顺序与金额链接，否则不计竞争闭环；
- 公网 API 是只读 GET，不暴露 RPC URL、钱包地址、签名数据或 webhook；
- lint、格式化、类型检查、UI 构建、单元测试、合约测试与敏感信息扫描全部通过后才能部署。

## Non-goals

- 不修改实盘资金或签名权限；
- 不为了生成样本而广播已知负净收益交易；
- 不在本故事中为 Robinhood 混合路线或 BNB 路线授予实盘能力。
