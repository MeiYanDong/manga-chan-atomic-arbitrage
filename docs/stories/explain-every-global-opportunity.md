# Story：每一次全局机会都能解释去了哪里

## 用户结果

作为实盘经营者，我需要知道“确实没有净利润”和“程序没有拿到完整市场证据”的区别；如果出现机会、错失或失败，能够从
一个事件记录追到报价、模拟、签名、提交和回执，而不是只看到笼统的“没有机会”。

## 验收标准

- 有效零/负报价、RPC 错误、区块状态缺失、执行器不支持和策略门槛过滤分别统计；
- 面板只显示中文经营结论，并明确本轮证据完整、部分缺失、不可用或没有可评估路线；
- eventId 贯穿 Feed/周期触发、调度、固定区块、目录/图版本、搜路、报价与精确模拟；
- 如果签名，eventId 继续进入不可变 mutation plan、signed/broadcast/receipt 审计；
- 遥测不出现私钥、RPC URL、calldata、raw transaction 或完整可复制路线；
- 所有执行权限、净利润、Gas、nonce、余额、最终模拟与回执门禁保持原样。

## 非目标

- 本故事不增加池子、资金、签名并发或交易频率；
- 不把 Feed 当作 mempool，也不承诺任何成交或收益；
- 不解决 Global 子进程常驻化、本地完整池状态镜像或增量图更新；这些属于后续独立阶段。
