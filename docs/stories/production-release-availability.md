# Story: 发布不能挤掉经营面板和实盘监控

## 用户结果

作为经营者，我希望发布已经通过 CI 的版本时，生产机只完成必要构建和运行时读回，不因为重复跑重型测试而让公网面板长时间不可用。

## 验收标准

- PR 与 main 的 `quality` 仍执行完整 `npm run check`；
- 生产安装器不重复单元测试和确定性合约测试；
- 生产发布仍重建类型、UI、合约产物并执行秘密扫描；
- 看板可在当前来源索引规模下完成受控冷启动，且不越过 576 MiB 硬上限；
- 发布验收记录看板健康、内存峰值、公开 API 和不可变 release；
- 发布看板时不得重启、重配或重新授权签名 watcher。
