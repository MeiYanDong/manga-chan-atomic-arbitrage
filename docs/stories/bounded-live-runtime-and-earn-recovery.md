# Story：实盘进程不会被历史日志拖垮，公共 RPC 失败也不漏掉 Earn 检查

## 用户结果

作为实盘经营者，我希望程序长期运行时，历史证据越多不会让每次安全检查越来越重；官方公共 RPC
拒绝服务器访问时，Earn 仍能在明确成本边界内继续发现和验证机会。

## 验收标准

- 授权、nonce、Gas 盈亏和路线隔离只增量读取新增审计字节，完整账本不删除、不改写；
- 旧的超长普通 RPC 错误不进入长期内存，安全事件损坏仍立即失败；
- Earn 事件由托管 WSS 实时唤醒，重连重复日志不会重复唤醒；
- 公共 HTTP 轮询降至 60 秒恢复频率，公共 403 只在每次和每日预算均允许时回退托管 HTTP；
- 预算耗尽、单个事件源失败和没有净利润都不会被写成成交或收益；
- v12 授权绑定事件源、公共恢复频率、每日预算和每次唤醒预算；
- 进程在 320 MiB V8 与 512 MiB cgroup 边界内通过生产浸泡，并保持唯一 signer/nonce lane；
- 只有链上回执与余额变化才能计入实盘收益。

## 非目标

- 不删除或压缩历史审计证据；
- 不提高本金上限，不降低 Gas 或净利润门槛；
- 不把 WSS 事件、报价或进程存活当作成交证明；
- 不宣称完成常驻状态图和多进程求解器等后续架构阶段。
