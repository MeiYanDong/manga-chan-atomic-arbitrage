# v0.6.1 bounded source and projection validation

- Date: 2026-09-07
- Scope: local deterministic gates, copied public board projections and two signer-free public-RPC cycles
- Production status: not yet promoted; Linux artifact and production canary remain required

## Legacy migration fixture

The current production board's public `snapshot.json` and `source-catalog.json` were copied into a private temporary
directory. No signer state, credential or wallet file was copied. The v0.6.1 startup retention step reduced the copied
source catalog from 1,984 generic PoolManager facts to 58 facts whose currency matched an independently discovered
source target.

Migrating that bounded source file and the approximately 7.1 MB snapshot into a fresh SQLite v2 store produced:

- an approximately 18.7 MB current database;
- an initial material-evidence ledger of approximately 462 KB;
- only 886 additional JSONL bytes for the next unchanged current projection;
- `HEALTHY` SQLite quick-check and exact current projection parity.

The macOS process reached roughly 272 MiB RSS during the deliberately cold legacy migration. This result is why the
board-only unit uses a 320 MiB pressure threshold and a 384 MiB hard ceiling. It is not evidence of Linux production
headroom; that remains a canary gate.

## Public-RPC runtime

Two consecutive `board:once` runs used Robinhood's official public HTTP RPC, a temporary runtime directory and one
bounded coverage candidate. The board had no signer or broadcast path.

After the first source range:

- all LONG, Doppler and target-pool cursors were `45050000`;
- 590 PoolManager initialize events were decoded and 133 target-related pools were retained;
- 129 Doppler targets were indexed, while only 2 met the visible-row rule;
- SQLite schema v2 was healthy with parity true;
- peak RSS was `260161536` bytes.

After the second source range:

- all three cursors were `45100000`;
- 248 Doppler targets were indexed, 8 were visible, and 260 target pools were retained;
- the second-cycle JSONL delta was 400,224 bytes and the SQLite file delta was 622,592 bytes;
- the evidence table contained source/registry responses, receipt logs, board events and four compact checkpoints, with
  no repeated `OPPORTUNITY_PROJECTION` or `SOURCE_CATALOG_PROJECTION` rows;
- peak RSS was `250888192` bytes.

The JSONL increase is dominated by newly observed immutable source facts, not a copy of all 842 current candidates.
These runs prove local bounded behavior and cursor ordering. They do not prove opportunity profitability, exact
executor readiness, a transaction, a receipt, realized net profit or sustained production stability.

## Deterministic checks at this stage

`npm run check` passed on the release candidate. It covered formatting, JavaScript and Solidity lint, type checking,
the production UI build, compile verification, 123 of 123 Node tests, both deterministic Cancun contract suites and a
137-file secret scan. `npm audit --audit-level=high` also reported zero vulnerabilities. GitHub Actions and the Linux
artifact/install checks remain independent promotion gates.
