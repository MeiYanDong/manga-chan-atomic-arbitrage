# ADR 0066：竞争回执按原生结算资产保留经济证据

- 状态：Accepted
- 日期：2026-09-14

## 背景

Earn Vault 的闭环并不都以 WETH 结算。旧竞争快照只为 WETH 回执计算净额，其他回执虽然已经证明起始数量、
结束数量、原币毛利和 ETH Gas，却统一显示为“金额不确定”。这丢失了已知证据，也容易让用户误以为交易金额
本身无法解析。

## 决策

1. 每个闭环按结算资产保存输入、输出、原币毛利、decimals 来源和证据状态；USDG、WETH 与已链上核验的
   NVDA 使用显式元数据，未知资产保留原始整数而不猜 decimals。
2. 只有整笔回执都以 WETH 闭环时，才把 WETH 毛利与该笔 ETH Gas 按 1:1 合并成路线净额估算。
3. 非 WETH 回执展示原币毛利与 ETH Gas 两个已知量。没有同一区块、可执行的换价证据时，净利润保持待估值，
   不使用当前价、前端价或跨时点价格补齐。
4. 竞争者和路径排行聚合上述原生资产证据；“已估算 ETH 净收益”只覆盖可归一化的 WETH 回执，并明确不是
   对方钱包总利润或扣除私有基础设施成本后的经营利润。
5. 公共投影可以展示链上公开的竞争地址，但地址放在展开证据中；签名材料、RPC、webhook 和原始交易内容仍
   不进入投影。
6. 旧七日回执在只读 census 启动时按交易哈希重新读取并原子重写为新记录 schema，不改变扫描游标，也不计为
   新交易或新收益。

## 结果与边界

- 已知的 USDG/NVDA 毛利不会再被“未知”吞掉；
- 跨资产净利润仍然诚实地保持部分证据状态；
- 地址、路径和收益都能逐笔回到链上回执；
- 当前竞争面板仍只覆盖 Earn Vault 内部闭环，跨协议竞争需要后续独立归因模型。
