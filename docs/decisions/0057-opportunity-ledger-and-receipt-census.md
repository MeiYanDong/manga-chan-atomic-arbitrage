# ADR 0057：新增机会总账页与签名器隔离的竞争回执取证

- 状态：Accepted
- 日期：2026-09-13

## 背景

原有经营面板能回答收益、交易、资金与策略运行，但无法在一个产品页面内回答五个不同问题：

1. 现在哪些机会真正可执行；
2. 哪些仅接近门槛；
3. 哪些已被明确过滤，原因是什么；
4. 哪些是报价空档、过期或未知，而不是“没有机会”；
5. 是否存在可核验的外部竞争回执或已证明的被抢事件。

原有 `/api/v1/opportunities` 还会为每次全局页面刷新展开重型来源关系，这与经营页面的可用性目标冲突。

## 决策

1. 保留现有 `概览 / 交易 / 资金 / 策略` 页职责，只新增独立 `机会` 页；
2. 把当前候选归入 `NOW / NEAR / FILTERED / UNKNOWN` 四个互斥阶段，对外只展示中文业务结论与最小必要经济数据；
3. 使用轻量、分页的 `/api/v1/opportunity-ledger/*` 读模型，不在全局 15 秒刷新中请求全量重型机会投影；原策略页仅在被打开时请求最多 12 条摘要；
4. `NOW` 与 `NEAR` 的精确路线和本金在公网延迟 5 分钟显示；已过滤原因立即可见；
5. 新建无凭证、无钱包、无签名和无广播能力的 Earn 回执取证服务。它仅匹配四条已审查的 WETH 闭环，必须同时满足池子、代币方向、日志顺序与逐段金额衔接；
6. 竞争回执按 7 天窗口展示，公开精确路线同样延迟 5 分钟。外部经济结果只标记为 `ROUTE_RECEIPT_NET_ESTIMATE`，因为我们无法证明对方的所有私有费用与资产后状态；
7. `confirmedLostRaces` 在建立“我方同区块可执行反事实 + 外部交易先行改变状态”证据前保持 `null`，不把历史正价差或未知报价计为被抢；
8. 现有正净收益实盘通道继续无次数上限运行。首个 72 小时作为竞速证据观察窗口；不为凑样本发送明知负期望的交易，也不放宽当前更严格的失败 Gas 熔断。

> 2026-09-14：第 5 条的四路线匹配范围已由 [ADR 0058](0058-dynamic-earn-omnipool-cycle-graph.md) 取代；
> 服务现在识别任意连续、逐段金额衔接的 Vault 闭环，其无签名与证据边界不变。

## 影响

- 经营者可直接看到机会漏斗、筛选原因和证据空档；
- 公网常规刷新不再触发全量来源投影；
- 竞争者数据从 `UNKNOWN/PARTIAL` 开始，回溯完成前不对全市场下结论；
- 新服务不读取 RPC 凭证、钱包或签名状态，不拥有 nonce 通道；
- 本发布不使 Robinhood/BNB 跨平台只读路线自动获得实盘权限。

## 非目标

- 不把影子报价、历史 episode 或运行进程计为收益；
- 不修改合约、本金、正净收益门槛、签名器或广播方式；
- 不声称当前只读回溯能覆盖未审查的协议与私有 order flow。
