# ADR 0076：受保护的多策略公平调度

- 状态：Accepted
- 日期：2026-09-15
- 补充：ADR 0071、ADR 0074、ADR 0075

## 问题

共同 supervisor 已经串行管理 Earn、Global 和面板执行，但原循环把事件与周期恢复复用为同一个
`pending*Wake`。一次事件执行会把该策略的 `nextPeriodicAt` 重置为“现在加一个周期”；持续事件因此可以不断把
完整性恢复扫描向后推。Global 子流程还是最长的一条同步工作，一旦它持续运行或超时，Earn 周期覆盖和普通面板工作
也没有可验证的最大等待语义。

这不是利润计算错误，而是机会覆盖的公平性错误。事件工作集只覆盖已知依赖，不能替代周期旋转对新池、漏日志和长尾
路线的恢复检查。

## 决策

1. Earn 与 Global 共用一个 `ProtectedStrategyScheduler`，但继续通过唯一 supervisor 串行进入 signer/nonce 域。
2. 每个策略各自保留不可被事件改写的周期截止时间。只有实际领取该策略的周期任务，才推进它自己的下一截止时间。
3. 已逾期的周期任务先于事件与普通面板候选；多个逾期任务按最早截止时间和固定 lane 顺序选择。
4. 没有逾期周期时，事件按显式优先级、最早源时间和固定 lane 顺序选择。Earn Feed、Global Feed、Earn 公开日志分别
   使用受限优先级；优先级只决定只读/精确检查顺序，不授予签名权限。
5. 同一 lane 的连续事件继续使用 ADR 0075 的 dependency union 合并；更高优先级原因可接管标签，但不会丢掉低优先级
   事件的池和资产。
6. Global 的最小运行间隔只限制普通事件，不允许它阻止已经逾期的恢复任务，也不能阻止另一个可运行的策略。
7. 状态记录每个 lane 的下一截止时间、待处理事件、周期/事件运行次数、合并次数和最大周期迟到值；迟到必须显式，
   不能把受阻的恢复扫描描述为完整覆盖。

## 不变边界

- 搜索可以排队，签名与 nonce 仍严格串行；
- 不改变合约、钱包、授权 ID、本金、利润底线、Gas 上限、模拟、回调、广播或回执规则；
- 调度领取不是机会、正报价、签名、广播或收益证据；
- 单个同步子进程仍可能造成有界延迟。彻底消除长任务阻塞需要后续常驻只读 worker，不在本变更中假装完成。

## 验收

1. Earn 与 Global 同时到期时均先获得周期运行，事件留在队列中；
2. 一个周期内持续注入 Earn 事件，Earn 的周期截止时间保持不变并在到期时优先领取；
3. 公开日志与 Feed 合并后保留所有池，同时保留 Feed 的更高优先级原因；
4. Global 事件受最小间隔限制时，Earn 仍能立即运行；
5. 延迟领取的周期任务记录真实 lateness；
6. 全量门禁、GitHub Linux CI、不可变 release 和生产运行读回通过后才替换实盘进程。
