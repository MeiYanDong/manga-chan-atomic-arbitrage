# ADR 0060：Earn 与 Uniswap 共用受限资产图和通用原子执行器

- 状态：Accepted
- 日期：2026-09-14

## 背景

Earn 动态 Omnipool 图已经摆脱 AI/MOO 固定路径，但只能在 Earn 内部闭环。相同资产在 Earn、Uniswap v2、
v3 和 v4 之间出现价格偏差时，旧执行器无法在一笔交易内组合这些边，也不能用 USDG、WETH 之外的明确结算
资产闭环。逐协议脚本拼接会产生中间敞口；开放任意调用则会把发现器升级成不受约束的钱包代理。

## 决策

1. 用一张本地资产图统一表示 Earn Swap、Earn 非平衡加池/按比例退池、Uniswap v2/v3/v4 直接交换。
   资产类别和代币名称不参与机会准入；池、协议、方向、手续费和结算资产才是边界。
2. 当前 Earn Factory 全量资产与 USDG/WETH 结算枢纽自动进入 v2/v3 Factory 查询；v4 只接纳已审核引导池和
   持久化链上证明目录，不能根据一次事件临时扩大签名范围。
3. 默认结算资产为 USDG 和 WETH。其他资产必须在显式 allowlist 中，并且具有 Morpho 零费闪电流动性或执行器
   受保护库存，以及可把利润与 Gas 保守折算回 USDG 的可执行估值路径。
4. 部署一个 typed-only `UniversalAtomicExecutor`。它只识别六类动作，不接受任意 target/calldata；每步校验
   canonical pool、方向、最小输出和余额，结束时校验本金归还、残余资产、库存底线与最小利润。
5. 执行器支持 Morpho flashLoan 和库存两种资金模式。闪电贷必须在同一交易归还；库存模式不得消耗执行前
   基线。授权只在执行期间精确授予，并在结束前撤销。
6. 路径枚举包含 Earn BPT 溢价/折价模板与 2～4 跳跨场所简单闭环。组合爆炸时回退到三跳，并用事件相关性、
   BPT 模板和区块轮转组成有上限的每轮工作集；粗搜可以触达全部可用本金，正候选再做局部金额细化。每条路径
   只保留毛利最高的金额，USDG/WETH/额外资产轮流占位，每轮最多 16 个候选进入付费精确阶段。
7. Sequencer Feed 只作为低延迟唤醒信号。收到相关地址后仍读取受控 RPC 的当前精确状态、模拟、Gas、nonce
   和余额；Feed 内容本身不构成利润或签名证据。
8. 完整签名原文先持久化，再优先提交官方 Sequencer；只有同一份原文可回退到受控 RPC。不得重签一个参数
   不同的交易，也不得由第二进程竞争 nonce。
9. v7 授权绑定执行器源码/运行时代码哈希、结算资产、资金、图、路径、Feed、提交和每轮报价上限。生产切换
   必须停止旧 watcher、撤销 v6、清空未决 mutation、部署并验明执行器后重新授权。父 watcher 与执行子进程
   都逐项比较这些值；没有共享 v7 授权或显式一次性开关时，手工命令不能签名。

## 经济与证据门禁

- 公共节点负责目录和宽筛；只有毛利为正的精确候选才使用付费节点；
- `eth_call`、报价或 fork 只证明可模拟，不能计作实盘；
- 签名前要求同一函数、同一计划和同一 Gas limit 的最终模拟，净利润底线至少为 Gas 完整成本与 `0.1 USDG`
  等值利润中的较高者；
- 只有成功 receipt、`Executed` 事件、计划哈希、本金/资金模式和真实余额变化全部一致，才计入经营利润；
- 没有满足门禁的机会时保持武装扫描，不发送亏损探针。

## 影响与剩余限制

- 同一原子交易现在可以跨 Earn 与 Uniswap 组合，结算资产不再硬编码为单一 WETH；
- 新协议不能自动获得执行权限，必须新增 typed adapter、测试和新授权；
- 更长路径增加候选数，也增加 Gas、报价负担和状态漂移概率，因此保留工作上限和轮转覆盖；
- Feed 降低发现延迟但不保证排序优势；实际胜率和可扩资金量仍须由主网 receipt 逐步建立。
