# ADR 0067：路线级 Sequencer 投影与执行漏斗

- 状态：Accepted
- 日期：2026-09-14
- 取代：ADR 0064 的事件相关性规则

## 背景

授权 v9 已把事件轮限制为八条路线，但生产回读发现最近一次事件只命中 2～14 个地址时，USDG 的 5,764
条路线和 WETH 的 6,327 条路线仍全部进入“相关”集合。根因不是池子不足，而是路由筛选直接使用 Feed
命中的全部地址：WETH、USDG、Earn Vault/Router 和 v4 PoolManager 是大量路线共享的枢纽，任何一个共享
地址都能与几乎整张图相交。随后固定排序只取前八条，既消耗约八至十秒报价时间，也可能长期不检查真正变化
的路线。

这些数字来自持有签名权的全局 watcher、其子进程快照和生产审计记录，不是只读机会面板的候选队列。

## 决策

1. Feed 地址表分为四类：共享协议入口、具体池或 hook、图资产、结算枢纽。所有类别仍可用于识别原始消息，
   但只有具体池/hook 与非结算资产可以成为路线依赖。
2. 具体池/hook 单独命中即可触发。共享协议入口必须同时出现至少一个非结算资产；仅资产命中时，至少需要
   两个图资产且其中至少一个不是结算枢纽。协议入口加 WETH/USDG、两个结算枢纽或单个资产都只计入过滤。
3. 事件子进程只接收投影后的路线地址，不接收原始全部匹配地址。路线按依赖命中数、跳数和稳定 ID 排序，
   最多八条，不用无关路线补位。五分钟周期恢复继续轮转全图，承担完整性覆盖。
4. 新增每轮来源接收时间、精确扫描起止、来源到结论耗时、全路线数、相关路线数和实际报价路线数。公开经营
   快照只输出汇总计数与中文结论，不输出原始 Feed payload、calldata、授权 ID、RPC 或签名材料。
5. 竞争页新增“Feed 消息 → 相关信号 → 精确扫描 → 毛利轮次 → 净利过线 → 链上成交”漏斗。竞争者成交
   与我方漏单是两套证据；没有同区块反事实和提交时序时，已确认输掉的竞速保持 `UNKNOWN`。
6. Feed 与路线策略常量升级，授权版本升为 v10。v9 与 v8 均不能在新代码下继续运行；生产切换必须先停止、
   撤销旧授权、确认无未决 mutation，再生成新的 until-revoked 授权并读回。

## 不变边界

- 不降低任何净利润、Gas、余额、nonce、代码身份、模拟或回执门槛；
- 不增加每轮路线、付费 RPC 日额度、失败 Gas 额度或资金上限；
- 不把周期未覆盖、读取失败、毛利为正或竞争者成交写成我方可实现净收益；
- 只有成功 receipt、执行事件和余额效果一致时才记作利润。

## 验收

- `协议入口 + WETH/USDG` 不触发昂贵事件轮；
- `WETH + AI` 只把 AI 依赖投影给路线筛选；
- 具体池/hook 只触达使用该地址的路线；
- 多个非枢纽资产共同出现时，同时包含它们的路线优先；
- 周期恢复的 BPT 优先与确定性轮转不变；
- 生产事件回读不再出现 `touchedRoutes == totalRoutes` 的共享枢纽污染；
- 面板显示执行漏斗和延迟，但竞速输赢仍保持证据约束。
