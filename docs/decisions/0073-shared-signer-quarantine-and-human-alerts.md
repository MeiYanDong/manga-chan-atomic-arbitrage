# ADR 0073：共享签名域隔离、异步核账与用户提醒

- 状态：Accepted
- 日期：2026-09-15
- 补充并部分取代：ADR 0071 的 UNKNOWN 进程退出与告警文案

## 问题

生产上的一笔 Earn 原子交易已取得确定的回滚回执，但子进程把它作为异常抛给父 watcher。父 watcher 只看到
子进程非零退出，在没有未决 mutation 的情况下仍把结果升级为 `HALTED_INVARIANT`，从而停止了同一进程内的
全部发现与执行。即使直接忽略这次退出，旧的 nonce 计算也只累计成功交易，没有累计已确认回滚；下一次合法
nonce 仍会被误判为外部冲突。

UNKNOWN 的边界也过大。未决交易确实禁止同一钱包继续签名，因为所有协议共享一个 nonce 序列；但这不要求
停止无签名的市场扫描、事件接收和证据记录。与此同时，关键飞书检查器为了复用一个 URL 校验函数加载了完整
经营与链上依赖，且 systemd 只允许八个 task，真正的停机状态因而没有可靠送达。生产对照探针进一步证明：
纯 Node 在 `TasksMax=8` 下可以退出 0；一旦通过 `fetch` 建立 DNS/TLS 网络请求，同一限制稳定触发
`SIGABRT`，而 `TasksMax=16` 退出 0。原告警还把 nonce、授权和内部处理步骤直接发给用户，没有回答影响与
是否需要处理。

## 决策

1. 执行结果按证据而不是平台名称分类。成功回执、回滚回执、未知结果和本地不变量失败是四种不同状态。
2. 成功与回滚回执都结束该 mutation 并消耗一个 nonce。回滚只计入失败 Gas；只要既有失败-Gas和 Earn
   长期正收益熔断器仍允许，watcher 继续处理其他候选。后台核账后来确认的回滚遵循同一规则，不得把已验证
   执行器标成停用。
3. UNKNOWN 只冻结 `SHARED_WALLET_NONCE_DOMAIN` 的新签名。父进程保持常驻，继续读取看板、Earn 事件和
   Sequencer Feed，并每五秒通过 mutation 类型对应的 reconciler 后台核对。核对完成后自动恢复签名。
4. 进程重启时允许在严格的一个-nonce窗口内带着同一授权的未决 mutation 启动为隔离态；超出该窗口、mutation
   不属于当前授权或不是下一个授权 nonce 仍是硬失败。
5. Earn、Global 和基础双币模块保留各自的协议适配与核账逻辑，但不再被当作三个独立的资金安全域。安全域由
   钱包、nonce 和资金所有权决定；平台只决定使用哪个 adapter。
6. UNKNOWN 前三分钟静默自动核对；持续超过三分钟才发一次关键提醒。提醒只写发生了什么、当前影响、系统已做
   什么和用户是否需要处理，不包含哈希、nonce、授权 ID、RPC URL 或内部状态码。
7. 经营日报只保留已确认净收益、成交、失败损失、当前实盘累计、可用资金、运行状态和是否需要处理；平台拆分、
   候选数量与地址数量留在经营面板，不进入日常打扰。
8. 关键提醒器只加载无第三方依赖的 Webhook 与 systemd credential 校验模块，将 `MemoryMax` 提高到
   128 MiB，并将允许 DNS/TLS worker 正常建立的 `TasksMax` 调整为 16。通知器仍没有 signer、RPC、重启或
   资金权限。
9. 日报的“今日净结果”和“本轮实盘累计”必须同时扣除盈利交易内已核算 Gas 与 canonical revert 的失败 Gas；
   失败成本仍单列作解释，但不能让标题数字漏扣后再冒充净收益。
10. watcher 收到 SIGTERM/SIGINT 时立即同步写入 `STOPPED_BY_SIGNAL`，不等待最长 60 秒的协议子进程返回。
    这样受控发布切换处于有界维护宽限，不会被一分钟健康检查误报为未知停机。

## 不变边界

- UNKNOWN 期间不能签名、广播新交易或复用 nonce；
- 不放宽最终报价、模拟、Gas、净利润、余额、合约身份、授权或回执门槛；
- 回滚不会被伪装成零成本机会消失，canonical Gas 必须进入损失与熔断统计；
- 一个协议适配器的普通回滚不能修改或停用其他执行器的部署身份；
- 通知内容简化不改变底层审计记录，原始证据继续保留在私有 append-only ledger。

## 验收

1. 测试证明 canonical revert 增加 nonce consumption，下一次收敛 nonce 可继续；
2. 测试证明未决交易允许未广播、pending 和已出块待核账三个严格状态，拒绝越界 nonce；
3. 源码门禁证明三类实盘执行都返回结构化回滚结果，不再用 throw 停止父 watcher；
4. watcher 在 UNKNOWN 中显示 `executionPaused=true` 和 `discoveryActive=true`，并调用对应 reconciler；
5. 三分钟内异步核账不发飞书，持续卡住才发一次，恢复只发一次；
6. 关键提醒器不再导入经营图或签名 journal，轻量依赖实测 RSS 低于旧实现；
7. 本地全量门禁、GitHub Ubuntu 门禁、生产 Linux systemd 校验和部署后运行读回全部通过后才恢复实盘。
8. 日报用包含失败 Gas 的精确日结果生成用户标题，受控停止信号在子进程结束前即可被健康检查读到。
