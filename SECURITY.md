# Security policy

Do not open a public issue containing a private key, RPC credential, signed raw transaction, wallet runtime ledger, server address, SSH detail or notification webhook.

Treat any key pasted into chat, logs or issue text as disclosed. The current wallet is a bounded canary only; rotate to a fresh wallet and redeploy before increasing capital.

The executor intentionally exposes its route and public deployment evidence. Reports about contract correctness, callback authorization, transaction recovery or secret leakage should be sent privately to the repository owner.
